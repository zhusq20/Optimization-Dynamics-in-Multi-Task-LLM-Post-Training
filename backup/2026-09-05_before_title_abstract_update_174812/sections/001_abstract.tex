\begin{abstract}
Multi-teacher on-policy distillation (MOPD) combines specialist feedback
in one student. We study how loss reduction and sparse parameter updates
relate to capability integration through three empirical questions.
First, we analyze how token averaging determines cross-domain weights
and within-domain response weighting. An exact finite-batch decomposition
provides an explanation to test against capability comparisons.
Second, building on established OPD sparsity, we examine sparse changes
in single-teacher and multi-teacher training, measure overlap between
teacher-conditioned updates at the same MOPD checkpoint, and ask whether
larger teacher distribution differences correspond to larger differences
between these update supports. Teacher--student distance is recorded
alongside the teacher-pair comparison. Third, we compare sampled-token
policy-gradient and top-$k$ losses in both single-teacher and multi-teacher
OPD. This final comparison tests whether update sparsity materially
changes under the two practical losses; further mechanism analysis is
conditional on observing a stable difference.
