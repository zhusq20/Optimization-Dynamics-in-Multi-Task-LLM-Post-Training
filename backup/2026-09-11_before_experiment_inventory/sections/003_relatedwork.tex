\section{Related Work}

MOPD combines domain-specialized teachers by scoring student-generated responses, using policy-gradient and distribution-based supervision \citep{ma2026mopdmultiteacheronpolicydistillation}. Open-MOPD studies capability imbalance in this setting and introduces interventions for task weighting and response behavior \citep{gao2026openmopddiagnosingfixingcapability}. Our normalization comparison connects the choice of averaging denominator to aligned capability trajectories and recorded token allocation.

Sparse parameter changes have also been studied in reinforcement learning and distillation. \citet{mukherjee2025subnetworks} investigate small parameter subsets that support RL fine-tuning. \citet{yu2026denseupdates} study sparse changes under dense supervision and evaluate restricted parameter updates. We connect this line of work to multi-teacher gradient geometry by measuring FP32 and BF16 changes, intervening on saved Adam state, and crossing input domains with teacher identities. These measurements explain how gradient support, update direction, and stored parameter activity can exhibit different patterns within the same student.
