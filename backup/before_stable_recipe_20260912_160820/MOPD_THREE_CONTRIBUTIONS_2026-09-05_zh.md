# 三个中心问题与当前证据

2026-09-12 修订。当前稿保持 token balancing → update sparsity / teacher overlap → supervision density 的顺序。摘要、引言与 Problem Formulation 只介绍问题与一般定义；模型、训练和评估细节放在各实验及附录。没有启动新训练、推理评测或局部探针，本轮只核验与整理已有结果。

## 1. 平均方式如何改变域权重、响应权重与能力？

GT 用 token 份额作为域权重；DT 固定域权重、域内按长度加权；DR 同时固定域权重与域内响应权重。固定 batch 的长度—梯度协方差恒等式解释两层区别。Open-MOPD §4.1 的 token-share 校正，在相同 batch、mask、目标权重下恰好对应 DT；这是已有方法的解释，不包装成新算法。

正文使用 GT/DT/DR **共同第 50 步**完整四域比较。DR/GT 第 100 步虽有个别评测，缺 DT，故不填入三方图表。后续归一化 checkpoint 留整组补充批注。

本轮新增已完成的固定 batch 实测：M-PG 第 100/250 步，各 3 个 bank，每域 8 responses。三种平均方式在相同模型与响应上计算原始梯度；正文解释 DT/DR 梯度方向差异，附录给六组、三种配对的完整表。恒等式数值检查只作复现验证，不当成额外理论贡献。

## 2. 参数变化是否集中，教师改变哪些共同参数？

联合 PG/I64 的完整共同参数轨迹延伸到第 250 步，FP32 与 BF16 分开。第 250 步 BF16 累计非零比例为 5.88% / 7.13%，90% 平方变化集中在 3.01% / 3.94% 坐标；FP32 变化明显更广。它是完整的**联合训练内部比较**。

以下三个缺口各保留整组批注，不把已有部分结果填进去：

1. 单教师与多教师的匹配单步/累计参数几何：单教师在线几何尚缺。
2. 同一联合学生与优化器状态下的逐教师 optimizer-step overlap：目前只有 raw-gradient overlap。
3. 逐教师 optimizer-step overlap 与 teacher JS 配对：前一项缺失，不能以梯度支持选择代替。

教师梯度矩阵、梯度—JS 散点、输入控制和 Adam 状态控制在附录各自作为完整诊断报告。独立训练的单教师终点不替代共同学生中的逐教师贡献。重叠描述坐标位置，方向需另看有符号变化；不使用“互不重叠子网”或“教师无梯度冲突”等超出证据的词语。

## 3. 词表监督范围如何影响更新集中与能力？

PG 与 I64 的完整能力配对：单教师第 100/250/500 步；联合第 50/100/250 步。新增 S-I64/500、M-PG/250、M-I64-DR/250 均核验原始回答。第 250 步 joint I64 的 Math/Code/GPQA 分数更高，IF 同为 26%；单教师端点仍呈域间取舍。附录给两个端点全部八个配对差值和区间。

局部主图更新为已完成的四 bank、4,096-token cap 比较：M-PG/100，共 16 responses、96 prefixes，对照 PG/I64/T64/full 的同状态步骤。它是完整的局部实验，不能替代单教师在线几何。原两 bank/256-token cap 的控制保留附录，并明确各自数据范围。其他 checkpoint 的完整局部数据归档，不扩展出独立研究任务。
