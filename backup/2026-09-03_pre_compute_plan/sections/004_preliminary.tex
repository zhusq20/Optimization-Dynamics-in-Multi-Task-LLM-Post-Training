\section{Setting: Fixed-Weight MOPD with Adaptive Counts}
\label{sec:setting}
% ============================================================================

A micro-batch contains $b=4$ prompts from one task, each with one sampled
response, and is processed in one backward pass. One optimizer step
accumulates $G=16$ micro-batches, 64 responses in total, before one AdamW
update. As in MOPD and Open-MOPD, each prompt receives one response and each
rollout batch is used for one update
\citep{ma2026mopdmultiteacheronpolicydistillation,
gao2026openmopddiagnosingfixingcapability}, so every micro-batch consists of
fresh prompts.

There are $M$ tasks (domains), each with a fixed teacher. Let $L_i(\theta)$ be
task $i$'s sampled-token reverse-KL loss, averaged over the valid tokens of a
response and then over the $b$ responses in a micro-batch
(Appendix~\ref{app:opd_estimators}). Fixed positive weights $w_i$ summing to
one define the objective
\begin{equation}
    F(\theta)=\sum_{i=1}^M w_i L_i(\theta).
    \label{eq:fixed_multitask_objective}
\end{equation}
Our experiments set $w_i$ proportional to the inverse of task $i$'s loss at
the initial student; any fixed choice works.

Task $i$ receives an integer count $m_i$ with $\sum_i m_i=G$ and
$m_{\min}\leq m_i\leq m_{\max}$; we use $m_{\min}=2$ and $m_{\max}=8$. Let
$g_{i,s}$ be the gradient of micro-batch $s$ of task $i$. The accumulated
gradient is
\begin{equation}
    A=\sum_{i=1}^M\frac{w_i}{m_i}\sum_{s=1}^{m_i}g_{i,s},
    \label{eq:batch_gradient_observation}
\end{equation}
which the trainer obtains by multiplying each micro-batch loss by $w_i/m_i$
before its backward pass. Conditional on the student state and the counts,
$\mathbb E[A]=\nabla F(\theta)$ for every allocation, so the counts change
the variance of the gradient estimate but not the objective. Averaging all
tokens of a step together would instead give task $i$ an effective weight that
grows with both its count and its response length; this is the length-driven
imbalance that Open-MOPD reports, and the per-response mean together with the
$w_i/m_i$ factor removes it by construction. Table~\ref{tab:notation} in the
appendix lists the notation.
