\subsection*{AI use statement}

We used generative AI tools for language editing and manuscript organization.
The authors reviewed every assisted revision and take responsibility for the
text, claims, proofs, code, and experimental results.

\subsection*{Ethics statement}

The study evaluates optimization methods for existing language models with
reasoning and instruction-following datasets and automated verifiers. Model and
dataset biases can affect capability scores. We record data provenance, invalid
outputs, and verifier failures to support careful interpretation.

\subsection*{Reproducibility statement}

Section~\ref{sec:experiments} specifies the micro-batch composition, fixed
objective weights, integer allocation, resource accounting, baselines,
held-out evaluation, and matched prompt streams. The released
artifact includes controlled-check code and seeds, the run configuration file,
model and tokenizer
revisions, initial-loss weights, prompt streams, optimizer and allocation
states, micro-batch counts, noise and timing logs, per-prompt evaluation output,
and source data for every figure and table.
