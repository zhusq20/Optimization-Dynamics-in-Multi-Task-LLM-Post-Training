联合 PG 的 MATH-500 从 55.6% → 66.4%，IFBench strict 从 17.3% → 14.7%。先用领域评估看保留和退化，再检查 KL、长度与 token 份额。局部 BF16 探针用于机制解释。

每张图单独导出 PDF / PNG / SVG。所有静态训练曲线保留原始点、默认不平滑。评估点只来自完整核验产物；单个训练 seed 不绘制虚假的置信区间。

数据来源与缺口

原始scalar镜像由训练代码在同一次调用中先写JSONL，再提交给 wandb.log(metrics)。本页使用这些完整本地镜像，没有经W&B网页抽样。浏览器链接可打开原run。

Policy entropy 未记录，未用负log-probability冒充；GPU成本比较尚未完成跨续训的统一核算。Student64→I64的切换点保留：DR 137、DT 152、GT 151、单任务101。100步评估属于父轨迹。
