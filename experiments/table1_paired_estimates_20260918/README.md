# Table 1 paired uncertainty estimates

These are model-based paired sampling intervals, not current question-level bootstrap results. The user authorized estimation because current question outcomes were unavailable. All 44 reported domain scores were retained.

Run `estimate_intervals.py` with Python and NumPy from the repository. It reads Table 1 domain scores, calibrates variance ratios from the frozen archive revision, writes `estimated_intervals.json`, and generates Table 1 and `contrast_table.tex`. The archive commit and SHA-256 hashes are recorded in the JSON. Saved `calibration_*.json` files are historical inputs, not current outcomes.

The script uses 100,000 Gaussian parametric-bootstrap replicates (seed 1042, antithetic draws), domain-stratified means, and the score-lattice variance floor. GPQA uses 198 question clusters; the variance calibration already reflects four-response question averaging. Model comparisons are conditional estimates and do not measure training-seed variation. The appendix describes the transfer from the historical 128-question code evaluation to the current reported 1,055-question protocol.

Sensitivity results double the transferred variance ratios and compare with the independent Bernoulli reference. Neither the narrow nor wider method-comparison intervals exclude zero.

`validation.json` records the numerical checks. Compilation and visual review use `tmp/pdfs/paired_interval_build` and `tmp/pdfs/paired_interval_qa`. Only the generated contrast table is allowlisted for Overleaf; the analysis inputs and code remain local under the repository's existing publication policy.

This calculation supersedes the marginal uncertainty in Table 1 generated by `experiments/table1_sync_20260918/sync_table1.py`; do not rerun that older script after this one without regenerating the paired estimates and checking the accompanying narrative.
