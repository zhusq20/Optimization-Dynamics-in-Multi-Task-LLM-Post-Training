# Bundled Chinese UI font

MOPD Figure Sans is a renamed glyph subset of Noto Sans CJK SC Regular, distributed under the accompanying SIL Open Font License. The HTML embeds the font for offline display.

Source: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
