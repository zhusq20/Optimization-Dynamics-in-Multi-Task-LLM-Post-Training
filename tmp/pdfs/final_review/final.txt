A BSTRACT
Multi-task LLM post-training makes two separate decisions. Teacher-loss weights
define the optimization target, while task probabilities allocate rollout and teacher
compute. Using one mixture for both decisions changes the target whenever the
task schedule changes.
We study systems that draw one task before each task-homogeneous update. The
sampled gradient receives its target weight divided by its sampling probability.
Standard AdamW squares this factor in its second-moment update, so the optimizer state changes with the sampling proposal. We replace that square with
a single factor. This one-line change makes the expected first- and secondmoment changes match the baseline whose task probabilities equal the target
weights. Gradient-Preserving Adaptive Sampling (GPAS) then measures task gradient scale in the lagged AdamW metric and samples in proportion to target weight
times measured scale. Cost-GPAS also divides by the square root of measured task
time. The cost rule is the one-draw form of cost-constrained Neyman allocation.
In a controlled three-task study, GPAS reduces AdamW-metric estimator error to
0.697 of uniform sampling. Raw gradient-norm sampling reaches 7.178 times the
uniform error in the same metric. A second controlled test verifies the AdamW
moment correction under a proposal different from the target mixture. GPAS
stores one scale and one runtime estimate per task and reuses the gradient and
timing produced by each training step.

I NTRODUCTION

Multi-task post-training spends very different amounts of optimization compute on tasks that appear
equally often. In Open-MOPD, instruction-following data account for 20.3% of prompts and only
0.99% of gradient tokens. Early per-token reward magnitudes also differ by a factor of 4.9 (Gao
et al., 2026). A nominal data mixture can therefore provide a poor description of the updates received
by each task.

R ELATED W ORK

Changing the target and changing the allocation. Multi-task methods often change loss weights
or gradient directions to improve a capability trade-off (Sener & Koltun, 2019; Yu et al., 2020; Liu
et al., 2024; Chen et al., 2018). DRATS, D3 -MOPD, and Open-MOPD’s gap-following schedule
use task progress to change the training target (Corrado et al., 2026; Sun et al., 2026; Gao et al.,
2026). Importance-sampling methods keep a fixed target and change example frequency to reduce
gradient error or compute (Alain et al., 2015; Katharopoulos & Fleuret, 2018; Mohri et al., 2026).
GPAS is in the second group. A curriculum can supply a time-varying target first, after which GPAS
allocates task draws for that target.
Multi-teacher post-training. MOPD routes student rollouts to task teachers and trains a shared
student with dense token feedback (Ma et al., 2026). Open-MOPD identifies token count, reward
scale, and stale rewards as sources of unequal update budgets (Gao et al., 2026). D3 -MOPD uses
teacher-loss gap and descent velocity to update the domain mixture (Sun et al., 2026). Teacher
mixtures can also create cross-domain capability transfer and a mixture-dependent seesaw (Li et al.,
2026). The cross-domain transfer results motivate our use of teacher loss for objective comparisons
and separate benchmark reporting for capability.
Sampling with optimizer state and cost. Gradient-norm importance sampling reduces the second moment of an SGD estimate (Alain et al., 2015; Katharopoulos & Fleuret, 2018). Cost-aware
sampling adds a square-root cost correction and provides convergence guarantees beyond convex
objectives (Mohri et al., 2026). The same allocation shape appears in classical Neyman allocation
(Neyman, 1934; Cochran, 1977). Adaptive optimizers create an extra interaction because the sampling weight is squared in the second-moment state (Lahire, 2023). GPAS uses an AdamW metric
whose population target remains fixed under proposal changes.

The Uniform run supplies checkpoints at the start, middle, and end of training. At each checkpoint,
we collect 16 task batches per task. Collection stores sufficient statistics in place of full gradient
copies whenever a scalar or fixed projection is enough.
The study answers four questions. First, Pearson and Spearman correlations compare raw gradient
norm and AdamW-metric norm with the task-dependent part of the next AdamW update. Second,
the cached gradients give M (q), J(q), and the χ2 gap in Equation 14 for every proposal. Third, gradient replay measures proposal-dependent drift in v under standard and moment-consistent AdamW.

The student is a fixed revision of Qwen3-1.7B (Qwen Team, 2025). Four same-origin teachers
specialize in mathematics, code, instruction following, and science question answering. The paper
reports the model and tokenizer revisions, teacher checkpoints, and each teacher’s score on its own
domain.
Each optimizer step samples one task and uses one task-homogeneous batch. A batch targets 65,536
valid response tokens; the logs also report the realized number of responses for each task. Every
response is averaged over its valid tokens, followed by an average over responses. A shared norm
clip is applied to Gi before sampling correction. The optimizer receives Gi and w separately, uses
wGi for m, and uses wG2i for v.
Runs use an 8,192-token response cap, temperature 1, top-p 1, an eight-step round-robin warm start,
γ = 0.95, and qmin = 0.05. A 300-step pilot uses one paired seed for Uniform and GPAS. The main
comparison uses 400 steps, with the pilot checkpoints reused. The five primary fixed-target methods
use three paired seeds; the moment ablation uses two. Methods within a seed share initialization,
per-task data order, and evaluation prompts. Teacher loss is evaluated every 50 steps, and capability
benchmarks are evaluated at the endpoint.

D ISCUSSION AND C ONCLUSION

GPAS separates the weighted teacher-loss target from compute allocation. Moment-consistent
AdamW keeps the expected first- and second-moment changes equal to the baseline q = λ. GPAS
then allocates task draws using gradient scale in AdamW’s lagged metric, and Cost-GPAS also accounts for task time. The identity metric recovers gradient-norm importance sampling.
The controlled estimator study supports the local allocation result. GPAS reduces AdamW-metric
error by 30.3%, while raw gradient-norm sampling performs poorly in the constructed AdamW
geometry. The moment-state experiment checks the one-line AdamW change directly. Frozengradient replay applies the same measurements to LLM gradients. The matched MOPD design
measures the connection between local error and teacher-loss efficiency.
Three boundaries guide interpretation. First, matching expected moment changes still allows different parameter paths because task order changes the realized gradients. Low-discrepancy task
schedules may reduce this path dependence and are a useful direction for future work. Second,
GPAS uses recent gradients and a lagged optimizer state. Score-age logs and frozen-gradient replay
measure the quality of this approximation. Third, Cost-GPAS minimizes the uncentered secondmoment objective in Equation 10. Appendix F of Mohri et al. (2026) connects this objective to
optimization rates, while GPU-hour curves measure its practical value.
The main design principle is simple: choose the teacher-loss objective first, then allocate expensive
task steps for that objective. The same separation lets GPAS compose with a curriculum by applying
the allocation rule after each target update.

B.4

S TRICT CURRICULUM DECOMPOSITION

An online curriculum can generate different target sequences after a proposal changes the training
path. Our paired decomposition fixes this source of variation. Native D3 first records its target
sequence λ1 , . . . , λT for each seed. The paired D3 target + GPAS run replays that sequence and
changes only qt . Both runs share initialization, per-task data order, and evaluation prompts.
D3 -Proposal-IC serves a separate purpose. It keeps λi = 1/4, forms qt from the published lossgap and descent-velocity signal, and applies λi /qt,i . Its comparison with GPAS measures proposal
quality under one fixed teacher-loss target.
B.5

S AMPLER STATE AND OPTIMIZER INTERFACE

Each checkpoint stores the score average, runtime average, observation count, score age, probability
floor, and current proposal for every task. The optimizer checkpoint stores the usual AdamW state
and a flag identifying the second-moment rule. Resume tests compare the next proposal and the next
optimizer state before and after serialization.
The main theory uses the task gradient before norm clipping. The training code uses a shared emergency clip before importance correction and reports the clip rate by task and method. A triggered
clip defines a clipped update field for that step. The fixed-objective interpretation is reported together
with this rate.
