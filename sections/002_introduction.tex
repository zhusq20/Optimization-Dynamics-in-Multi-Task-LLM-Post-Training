\section{Introduction}
\label{sec:intro}
% ============================================================================

Post-training one model on mathematics, code, instruction following, and science
requires two decisions. Target weights state which capabilities the objective
values. Sampling probabilities decide which task receives the next rollout,
teacher call, and update. Keeping target weights and sampling probabilities
separate makes both decisions visible.

Many systems use the sampling ratio as the task weight. Sampling a weak or cheap
task more often then changes the model objective, so the resulting capability
trade-off can come from the objective, the compute schedule, or both. A coupled
design makes optimization efficiency difficult to measure.

Response length creates a second ambiguity. In a prompt-balanced mixed batch,
global token averaging gives long-response tasks a larger coefficient. Recent
MOPD work diagnoses this imbalance and changes domain loss weights
\citep{gao2026openmopddiagnosingfixingcapability}. Our training objective gives
each response equal weight inside a task-homogeneous batch.

Teacher selection is a prerequisite for OPD. A wide teacher--student gap can
create extreme token log-ratios, whereas a narrow gap supplies little signal.
Recent studies report stronger transfer at moderate distributional overlap
\citep{ma2026mopdmultiteacheronpolicydistillation,
wang2026demystifyingopd,mayingzi2026onestudentmanyteachers}. We train teachers
from the student initialization, audit them on student rollouts, and study task
allocation only within the selected teacher set.

Suppose task $i$ has target weight $\lambda_i$ and sampling probability $q_i$.
Multiplying its sampled gradient by $\lambda_i/q_i$ keeps the conditional mean
equal to the target mixture. The sampling probabilities can then allocate
compute while the target mixture stays fixed.

Gradient-Preserving Adaptive Sampling (GPAS) applies classical importance
sampling at the task-batch level. GPAS scores task gradients in a metric induced
by the training optimizer, then assigns more probability to tasks with larger
scores. The identity metric recovers raw-gradient sampling for SGD; for AdamW,
we use the lagged preconditioner from its stored second moment. A moving average
estimates each task score from completed updates. A probability floor limits
stale scores and large importance weights. Cost-GPAS also uses measured task
time.

The controlled experiment checks the sampling formulas with known gradient
distributions and costs. The large-model experiments use frozen gradient banks
to compare raw gradients, GPAS scores, and measured AdamW task steps. Paired
training runs then measure teacher-loss progress per token and GPU hour. A GRPO
experiment tests the same task sampler with reward-based updates.

The paper makes three contributions:
\begin{itemize}
    \item We define a response-normalized task-batch interface that separates a
    fixed multi-task target from compute allocation in on-policy post-training.
    \item We derive task allocation in an optimizer-induced metric, recovering
    raw-gradient sampling for SGD and a lagged-preconditioned rule for AdamW. A
    cost-aware version also uses measured end-to-end task time, and both
    samplers estimate their scores online.
    \item We validate the estimator calculation and specify direct MOPD and
    GRPO tests that connect score quality to progress per token and GPU hour.
\end{itemize}

Section~\ref{sec:theory} presents GPAS; Section~\ref{sec:experiments} gives the
MOPD and GRPO studies. The appendix contains proofs and implementation details.
