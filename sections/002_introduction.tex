\section{Introduction}

Multi-teacher on-policy distillation (MOPD) trains a shared student on its own responses using feedback from domain specialists \citep{ma2026mopdmultiteacheronpolicydistillation}. Its appeal is direct: mathematics, code, instruction following, and science can share one model while retaining specialized supervision. Its optimization is less transparent. Equal prompt quotas can yield unequal token weights, different teachers can act on overlapping coordinates, and a dense loss can leave only a small visible change in stored weights.

These observations concern three successive transformations. Loss averaging determines how responses contribute to the gradient. Adam combines that gradient with accumulated state. Finite-precision writeback determines which changes appear in the model checkpoint. Understanding the resulting capability allocation requires measuring these transformations separately. Token-share balancing already motivates interventions in Open-MOPD \citep{gao2026openmopddiagnosingfixingcapability}, while recent RL and distillation studies document sparse parameter changes and investigate restricted parameter updates \citep{mukherjee2025subnetworks,yu2026denseupdates}. We examine how these phenomena interact in a common multi-teacher setting.

Our study uses a Qwen3-1.7B student initialized from the common parent of four RL teachers, with shared prompt formatting, decoding conventions, and optimizer settings. Six training configurations provide thirteen completed capability suites. Measurements from the joint sampled-gradient checkpoint at update 100 connect these trajectories to teacher-conditioned gradients and controlled local Adam steps. Two fixed response banks support comparisons of input domains, teacher identities, and vocabulary supervision.

Three findings organize the paper. First, averaging rules induce different early capability tradeoffs; fixing domain weights and fixing response weights are separate operations (Section~\ref{sec:normalization}). Second, the apparent sparsity of a parameter change depends strongly on precision and optimizer history, and teacher-conditioned gradient directions depend on input composition (Section~\ref{sec:subnetworks}). Third, writeback density can remain nearly constant while the direction changes with the supervision estimator (Section~\ref{sec:density}). These findings provide a concrete account of how supervision is converted into parameter movement during multi-teacher distillation.
