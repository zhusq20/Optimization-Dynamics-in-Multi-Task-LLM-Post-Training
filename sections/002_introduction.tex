\section{Introduction}
\label{sec:intro}
% ============================================================================

Multi-teacher on-policy distillation (MOPD) uses specialist teachers to train a
single student on several domains
\citep{ma2026mopdmultiteacheronpolicydistillation}. A task mixture usually
specifies both the learning objective and the share of training compute. An
adaptive schedule can therefore change what the student learns while changing
where compute is spent. Differences in teacher-loss scale, response length, and
serving time make the two effects difficult to separate
\citep{gao2026openmopddiagnosingfixingcapability,sun2026d3mopd}.

We study a focused question: given a fixed MOPD objective, how should a training
run allocate teacher tasks? We separate an objective weight from a task's
inclusion probability. Importance correction preserves the weighted gradient
when the execution policy changes. We also treat the number of tasks in one
optimizer update, denoted by $K$, as a system and optimization choice. A small
$K$ permits teacher reuse and frequent updates. A large $K$ covers more tasks
per update and reduces task-selection noise; full coverage removes it.

Our method, Gradient-Preconditioned Adaptive Sampling (GPAS), measures each
task's gradient after the diagonal scaling used by the current optimizer. It
assigns more task units to gradients with larger scaled magnitude. Cost-GPAS
also favors tasks with shorter measured critical paths. Both rules leave the
declared task objective unchanged. Figure~\ref{fig:controlled_checks} gives a
controlled example in which raw gradient norms select the wrong tasks for
AdamW, while GPAS reduces error in AdamW's local geometry.

Adaptive task sampling also changes the squared gradients seen by conventional
AdamW. We use a taskwise second-moment observation whose conditional mean stays
fixed when the task proposal changes. This creates a common local AdamW geometry
for comparing Uniform, GPAS, and Cost-GPAS. Conventional AdamW remains an
experimental baseline because the two moment definitions can produce different
training paths.

The paper makes three contributions:
\begin{itemize}
    \item We define MOPD task allocation as an execution policy under a fixed
    per-response teacher-loss objective, with exact importance correction for
    updates containing $K$ tasks.
    \item We propose GPAS and Cost-GPAS, two simple allocation rules based on
    optimizer-scaled gradient magnitude and measured task time. We give each
    formula a direct frozen-checkpoint or end-to-end test.
    \item We provide controlled evidence for the estimator and AdamW moment
    calculations, together with a four-teacher evaluation at
    $K\in\{1,2,4\}$ that measures loss per response, loss per GPU hour, memory,
    and teacher switching.
\end{itemize}
