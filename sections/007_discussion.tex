\section{Discussion}

The main empirical lesson is that parameter statistics can hide differences that matter for interpreting MOPD. Adam's accumulated moments make distinct current gradients produce similar updates, and BF16 storage makes dense FP32 parameter changes appear sparse. Neither observation establishes that teachers train disjoint parameter subsets or improve tasks without interference. Conversely, similar single-step concentration under different vocabulary losses does not imply the same task scores after training. In our runs, loss normalization has little effect on the final top-64/Adam mean, whereas the relative performance of sampled-token and top-$k$ supervision changes with the task and checkpoint.

The scope of these findings is limited to one Qwen3-1.7B student and four teachers fine-tuned from the same initial model. The normalization curves summarize seeds 42--44; the expanded objective/optimizer comparison and additional test use seed 42. Repeated response batches measure diagnostic sampling variation, while question-bootstrap intervals measure evaluation uncertainty for fixed checkpoints; neither estimates variation between independent training runs. The top-64 intersections in the single-step comparisons already retain almost all student probability, so the results do not characterize low-probability vocabulary tails or more dissimilar teachers. Appendix~\ref{app:math_overlap_sensitivity} removes four known overlapping mathematics questions as a sensitivity check, rather than an exhaustive contamination audit. Broader conclusions about training stability or compute efficiency require repeated runs with matched compute budgets.
