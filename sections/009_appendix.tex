\subsection{Importance correction and taskwise moments}
\label{app:moment_target_proof}

Let $Z_i$ indicate that task $i$ enters the selected set. Selection precedes
generation, so $Z_i$ and the potential task-unit gradient $g_i$ are conditionally
independent. Since $\mathbb E[Z_i]=p_i$,
\begin{equation}
\mathbb E\!\left[\sum_i Z_i\frac{w_i}{p_i}g_i\right]
=\sum_i w_i\mathbb E[g_i].
\end{equation}
Replacing $g_i$ with its element-wise square gives
\begin{equation}
\mathbb E\!\left[\sum_i Z_i\frac{w_i}{p_i}g_i^2\right]
=\sum_i w_i\mathbb E[g_i^2].
\end{equation}
Both identities hold for any fixed-size design with the stated marginals.

At $K=M$, write $\bar g=\sum_i w_i g_i$. The difference between taskwise and
conventional mixed-batch square observations is
\begin{equation}
    \sum_i w_i g_i^2-\bar g^2
    =\sum_i w_i(g_i-\bar g)^2\geq0
    \label{eq:mixed_moment_dispersion}
\end{equation}
coordinate by coordinate. This task-dispersion term explains why the two AdamW
variants can use different effective step sizes.

\subsection{Estimator error for fixed-size task sets}
\label{app:variance}

Let $h_i=\mathbb E[g_i]$, $h=\sum_iw_i h_i$, and
$e_i=\mathbb E\|D(g_i-h_i)\|_2^2$. An independent-inclusion calculation gives
\begin{equation}
\mathbb E\|D(\widehat g-h)\|_2^2
=\sum_i w_i^2\left[
\frac{1-p_i}{p_i}\|Dh_i\|_2^2+\frac{e_i}{p_i}\right].
\label{eq:independent_variance}
\end{equation}
Since $r_i^2=\|Dh_i\|_2^2+e_i$, the part controlled by $p$ equals
$V(p)$ plus a constant.

For an exact-$K$ set, let $p_{ij}$ be the probability that tasks $i$ and $j$
enter together. The complete error adds
\begin{equation}
2\sum_{i<j}w_iw_j
\left(\frac{p_{ij}}{p_ip_j}-1\right)
\langle Dh_i,Dh_j\rangle.
\label{eq:fixed_size_variance}
\end{equation}
This term depends on task alignment and the subset design. The experiment
enumerates every subset for four tasks and evaluates Equations
\ref{eq:independent_variance}--\ref{eq:fixed_size_variance} together.

\subsection{GPAS and Cost-GPAS solutions}
\label{app:allocation_proofs}

Write $a_i=w_i r_i$. For $V(p)=\sum_i a_i^2/p_i$, the interior optimality
condition gives $p_i=a_i/z$. Coordinates that reach either probability limit
stay at that limit, and the same condition applies to the remaining coordinates.
This is Equation~\ref{eq:gpas_proposal}.

For task times $t_i>0$, Cauchy--Schwarz gives
\begin{equation}
\left(\sum_i p_i t_i\right)
\left(\sum_i\frac{a_i^2}{p_i}\right)
\geq\left(\sum_i a_i\sqrt{t_i}\right)^2.
\end{equation}
Equality holds at $p_i\propto a_i/\sqrt{t_i}$, which gives
Equation~\ref{eq:cost_gpas_proposal}. The implementation numerically solves the
small constrained problem when a probability limit is active.

\subsection{MOPD gradient and probe scaling}
\label{app:opd_estimators}

For a student-generated prefix $z$, write
$q_v=\pi_\theta(v\mid z)$ and $t_v=T_i(v\mid z)$. The sampled-token reverse-KL
score is
\begin{equation}
    \operatorname{sg}\!\left[\log\frac{q_V}{t_V}\right]
    \nabla_\theta\log q_V,\qquad V\sim q.
\end{equation}
The implementation averages token contributions within a response and then
over the fixed task unit. All allocation claims use this conditional,
rollout-fixed surrogate gradient.

The full task unit averages 16 prompt groups. An eight-response probe contains
two groups. For task mean $h_i$ and prompt-group noise $b_i^2$, the full-unit
score is
\begin{equation}
    r_i^2=\|Dh_i\|_2^2+b_i^2/16.
\end{equation}
The probe refreshes the maintained mean and group-noise estimates. Probe time is
tracked in its own resource counter.

\subsection{Response-clock AdamW and system logs}
\label{app:sampler_state}

If $\beta$ denotes the AdamW decay after one task unit, a $K$-task combined
update uses $\beta^K$. This matches the total decay assigned to $K$ processed
units. Decoupled weight decay uses the matching compounded coefficient. A unit
test compares the decay of stored moments and parameters against $K$ repeated
clock advances. A resume test reproduces the next selected set, task order,
moment observation, and parameter update.

Every checkpoint stores $K$, inclusion probabilities, selected set and order,
scale and time averages, observation ages, probes, resident teacher, and AdamW
variant. Each task unit logs prompt, response, and token counts; gradient norm,
clipping, and overflow; transfer phases; rollout, scoring, backward, and
optimizer time; GPU count; and peak HBM. Frozen-bank source units, proposals,
and held-out errors are released with the run data.
