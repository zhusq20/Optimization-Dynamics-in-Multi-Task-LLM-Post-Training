\subsection{Sampled-token OPD}
\label{app:opd_estimators}

Fix a student-generated prefix $z$. Write
$p_v=\pi_\theta(v\mid z)$ and $\tau_v=T_i(v\mid z)$. The reverse-KL ascent
gradient at prefix $z$ is
\begin{equation}
    u_i(z)
    =
    \sum_v p_v\log\frac{\tau_v}{p_v}
    \nabla_\theta\log p_v.
    \label{eq:full_token_rkl_update}
\end{equation}
For a token $V$ sampled from $p$, the sampled-token gradient is
\begin{equation}
    U_i(z,V)
    =
    \operatorname{sg}\!\left[\log\frac{\tau_V}{p_V}\right]
    \nabla_\theta\log p_V,
    \qquad
    \mathbb E[U_i(z,V)\mid z]=u_i(z).
    \label{eq:pg_prefix_unbiased}
\end{equation}
Response normalization averages the prefix gradients according to
Equation~\ref{eq:response_normalized_update}.

\subsection{Corrected KL-trajectory proposal}
\label{app:kl_trajectory}

KL-Trajectory adapts the learning-progress signal of D$^3$-MOPD
\citep{sun2026d3mopd} to task-homogeneous updates. Let $\bar\ell_{i,m}$ be the
EMA of response-normalized reverse KL after the $m$th observed batch from task
$i$, and let $\ell_i^{(0)}$ be its warm-start mean. With window length $W$ and
$R$ non-overlapping windows, the score is
\begin{equation}
    z_{i,m}
    =\frac{\bar\ell_{i,m}}{\ell_i^{(0)}}
    \left[
      \frac{1}{R}\sum_{r=0}^{R-1}
      \frac{\bar\ell_{i,m-(r+1)W}-\bar\ell_{i,m-rW}}
           {\bar\ell_{i,m-(r+1)W}+\epsilon_{\mathrm{KL}}}
    \right]_+.
    \label{eq:kl_trajectory_score}
\end{equation}
Available windows replace $R$ during warmup. Max-normalization, a
temperature-controlled softmax, and the common floor give
$q_i=\operatorname{FloorSoftmax}(\widehat z_i)$. Multiplying the sampled
gradient by $\lambda_i/q_i$ changes only the proposal and preserves the target
in Proposition~\ref{prop:conditional_preservation}.

\subsection{Task-homogeneous GRPO gradient}
\label{app:grpo_update}

For task $i$, GRPO samples response groups from one prompt, computes
within-prompt advantages, and applies the standard clipped policy surrogate
\citep{shao2024deepseekmathpushinglimitsmathematical}. The implementation first
averages token terms inside each response and then averages responses inside the
task batch. The resulting clipped task gradient is $G_i$. The GRPO policy ratio
handles behavior-policy change inside a task, while $\lambda_i/q_i$ handles task
sampling.

\subsection{Frozen-gradient evaluation metric}

For an evaluation bank, let $\widetilde h=A_th$ be the full-mixture mean in the
selected optimizer metric, and let
$\widehat{\widetilde g}=A_t\widehat g$ be the transformed corrected draw. The
centered error is
\begin{equation}
    M(q)=\mathbb E\left\|\widehat{\widetilde g}-\widetilde h\right\|_2^2.
    \label{eq:empirical_estimator_mse}
\end{equation}
The experiment estimates $h$ and the expectation from held-out task batches.
Calibration batches supply $q$, so proposal construction and evaluation use
separate samples. The LLM evaluation uses the AdamW metric in
Equation~\ref{eq:adamw_lagged_metric}; the controlled experiment also reports
the SGD identity metric.

\subsection{Approximate-score penalty}
\label{app:score_approximation}

Let $q_i^*=\lambda_i s_i/Z$, where $Z=\sum_i\lambda_i s_i$, and let
$\widehat q_i=\lambda_i\widehat s_i/\widehat Z$. Write
$w_i=\lambda_i s_i/Z$ and $r_i=\widehat s_i/s_i$. Then
\begin{equation}
    \frac{V(\widehat q)}{V(q^*)}
    =\left(\sum_iw_ir_i\right)
     \left(\sum_i\frac{w_i}{r_i}\right).
\end{equation}
If $r_i\in[1-\delta,1+\delta]$, the Kantorovich inequality gives
\begin{equation}
    \frac{V(\widehat q)}{V(q^*)}
    \leq
    \frac{\big((1-\delta)+(1+\delta)\big)^2}
         {4(1-\delta)(1+\delta)}
    =\frac{1}{1-\delta^2}.
\end{equation}
The result concerns proposal quality for fixed scores. Model drift, observation
noise, and the probability floor are measured separately.

\subsection{Probability floor and saved state}

The online sampler fixes entries below $q_{\min}$ and renormalizes the remaining
active entries. A checkpoint stores every task's
score average, cost average, observation count, last-step time, task cursor, and
current proposal. Restoring the random state and task cursors reproduces the
next task draw and batch.
