\section{Related Work}
% ============================================================================

\paragraph{Task weighting and data allocation.}
Multi-task methods tune loss weights, alter gradient directions, or adapt data
schedules
\citep{sener2019multitasklearningmultiobjectiveoptimization,
yu2020gradientsurgerymultitasklearning,
liu2024conflictaversegradientdescentmultitask,chen2018gradnorm}.
Carefully tuned scalarization is competitive with specialized multi-task methods
in several settings \citep{kurin2022defense,xin2022current}. Language-model
training also adapts domain, rollout, or prompt distributions using learning
progress \citep{albalak2023efficient,wang2025dump,zheng2025greso,
gao2025promptcurriculum}. GPAS keeps task importance fixed and changes the data
and compute allocation.

\paragraph{Multi-teacher on-policy distillation.}
MOPD routes student rollouts to task teachers and trains a shared student with
dense token feedback \citep{ma2026mopdmultiteacheronpolicydistillation}.
Open-MOPD studies unequal token budgets, reward scales, and stale rewards
\citep{gao2026openmopddiagnosingfixingcapability}. D$^3$-MOPD updates the domain
mixture using teacher-loss gap and descent velocity \citep{sun2026d3mopd}.
Teacher mixtures can also create transfer and task trade-offs
\citep{li2026coinsidesdualnature}. These methods motivate reporting downstream
capability separately from the fixed teacher-loss objective used in our study.

\paragraph{Importance sampling for optimization.}
Gradient-norm sampling reduces the second moment of an SGD estimate
\citep{alain2015variancereductionsgddistributed,
katharopoulos2018samplescreatedequaldeep}. Cost-aware sampling adds a
square-root time correction \citep{mohri2026costawarelearning}; the same form
appears in Neyman allocation \citep{neyman1934representative,cochran1977sampling}.
Online samplers receive fresh information only for selected tasks, a setting
studied with bandit feedback
\citep{namkoong2017adaptive,salehi2017stochastic,borsos2018online}.
The useful scale depends on the optimizer: Euclidean gradient norm fits SGD,
while adaptive optimizers rescale coordinates \citep{lahire2023nonuniformadaptive}.
GPAS applies this observation to multi-teacher MOPD and pairs it with a fixed
task objective, taskwise AdamW moments, exact-$K$ task sets, and measured teacher
serving time.
