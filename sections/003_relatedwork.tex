\section{Related Work}
% ============================================================================

\paragraph{Multi-task optimization.}
Multi-task methods often learn task weights or modify gradient directions to
improve a capability trade-off
\citep{sener2019multitasklearningmultiobjectiveoptimization,
yu2020gradientsurgerymultitasklearning,
liu2024conflictaversegradientdescentmultitask,chen2018gradnorm}. GPAS starts
from task weights supplied by the user. GPAS changes the frequency of task
batches and keeps the weighted gradient fixed in expectation. A fixed target
makes optimization efficiency measurable under one capability objective.

\paragraph{Multi-task RL for language models.}
Joint RL post-training can show uneven gradients and uneven task progress
\citep{ramesh2026multitaskgrporeliablellm,
wu2025imbalancedgradientsrlposttraining}. Difficulty-based curricula sample
weak or slowly improving tasks more often \citep{corrado2026drats}.
Multi-Task GRPO learns robustness-oriented task weights and preserves its
realized batch ratios \citep{ramesh2026multitaskgrporeliablellm}. Our experiments
keep the target task weights fixed. Curriculum signals can still define a task
proposal, but the sampled gradient receives the same inverse-probability
correction as every other proposal.
In the GRPO transfer study, we adapt the absolute-advantage signal used by
self-evolving curricula as such a corrected proposal.

\paragraph{Multi-teacher on-policy distillation.}
MOPD routes student rollouts to domain teachers and trains one shared student
\citep{ma2026mopdmultiteacheronpolicydistillation}. Related systems use
task-specific teacher interfaces and language-specialized teachers
\citep{mayingzi2026onestudentmanyteachers,
xie2026languagespecializedmopd}. Open-MOPD identifies response length,
teacher--student gap, and reused rewards as sources of capability imbalance and
changes domain loss weights
\citep{gao2026openmopddiagnosingfixingcapability}. Other OPD studies report
unreliable token guidance under large teacher--student distribution mismatch
\citep{wang2026demystifyingopd,wang2026distilledrl}. Same-origin teachers and
moderate next-token overlap improve training stability while preserving a
useful learning signal
\citep{ma2026mopdmultiteacheronpolicydistillation,
mayingzi2026onestudentmanyteachers}. Our MOPD protocol uses four same-origin
teachers, task-homogeneous fixed-token batches, and one optimizer use per
rollout. D$^3$-MOPD adapts the domain mixture from normalized reverse-KL gap and
recent descent velocity to exploit asynchronous domain convergence
\citep{sun2026d3mopd}. In its formulation, the same mixture also weights the
MOPD objective. We adapt its trajectory signal as a corrected task proposal,
called D$^3$-Proposal-IC, so it can be compared with optimizer-aware sampling
under one fixed target.
GPAS changes the frequency of complete task batches and applies an inverse
sampling factor. Cost-GPAS adds measured GPU time for generation, teacher
evaluation, and model updates.

\paragraph{Importance sampling for stochastic optimization.}
Sampling examples from their gradient size and applying an inverse probability
factor can reduce stochastic-gradient variance
\citep{alain2015variancereductionsgddistributed,
katharopoulos2018samplescreatedequaldeep}. Cost-aware SGD further samples in
proportion to gradient scale divided by the square root of evaluation cost and
has been applied to GRPO \citep{mohri2026costawarelearning}. Non-uniform
sampling can interact nonlinearly with adaptive optimizers
\citep{lahire2023nonuniformadaptive}. PiKE adapts data-mixture weights
using gradient magnitude, variance, and interactions
\citep{li2025pikeadaptivedatamixing}.

Cost-Aware GRPO decides which already-generated sequences enter policy updates.
GPAS decides which task receives the next rollout, teacher call, and optimizer
step while preserving a user-specified multi-task objective. GPAS evaluates
complete task-batch gradients in an optimizer-induced metric and estimates task
scores from completed updates. Its SGD instance recovers classical
gradient-norm sampling; its AdamW instance uses a lagged preconditioner.
Cost-GPAS applies the published cost-aware sampling identity to the same
task-batch setting. Our contribution lies in fixed-target multi-task
allocation, response-normalized task batches, and optimizer-aware online
scores.
