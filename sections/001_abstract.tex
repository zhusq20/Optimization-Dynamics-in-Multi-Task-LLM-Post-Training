\begin{abstract}

Multi-teacher on-policy distillation (MOPD) uses several specialist teachers to
train one student. Existing task mixtures often combine two choices: the
importance of each task in the training objective and the compute assigned to
that task. We separate these choices and keep a per-response teacher-loss
objective fixed. We then introduce Gradient-Preconditioned Adaptive Sampling
(GPAS), which samples tasks using gradient scale after the current optimizer's
diagonal scaling. Cost-GPAS also uses the measured critical-path time of each
teacher task. A taskwise AdamW second moment keeps the local optimizer geometry
comparable when task probabilities or the number of tasks per update change.
Controlled experiments verify the estimator calculations: GPAS reduces
AdamW-scaled error by 28.3\% relative to uniform sampling, and Cost-GPAS reduces
the time-weighted error by 11.1\% in the same construction. We connect each
theoretical prediction to a four-teacher MOPD measurement at task widths
$K\in\{1,2,4\}$. The evaluation uses matched response budgets, end-to-end GPU
hours, teacher-switch traces, and conventional AdamW baselines. This design
tests when adaptive task allocation improves MOPD efficiency under a fixed
learning objective.

\end{abstract}
