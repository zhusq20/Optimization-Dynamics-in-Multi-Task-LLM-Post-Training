% ============================================================================
\section{A Fixed Objective and a Common AdamW State}
\label{sec:preliminaries}
% ============================================================================

Assume $M$ teacher tasks. Let $L_i(\theta)$ be task $i$'s reverse-KL loss,
averaged within each response and then over responses and prompts. Positive
weights $w_i$ sum to one and define the training objective
\begin{equation}
    F(\theta)=\sum_i w_i L_i(\theta).
    \label{eq:fixed_multitask_objective}
\end{equation}
The main MOPD study uses $L_i=\ell_i/\ell_i(0)$ and $w_i=1/M$. Each initial
loss $\ell_i(0)$ is measured once at the shared starting checkpoint. This choice
gives equal weight to relative improvement on each task.

A \emph{task unit} contains a fixed number of prompts and student responses.
Let $g_i$ be its average gradient. An optimizer update selects a set $B$ of
exactly $K$ tasks. The inclusion probability of task $i$ is $p_i$, with
$\sum_i p_i=K$. The corrected update gradient is
\begin{equation}
    \widehat g=\sum_{i\in B}\frac{w_i}{p_i}g_i.
    \label{eq:importance_estimator}
\end{equation}
Task selection happens before rollout generation. Conditional on the current
student state,
\begin{equation}
    \mathbb E[\widehat g]=\sum_i w_i\mathbb E[g_i].
    \label{eq:importance_unbiased}
\end{equation}
The objective gradient is therefore fixed for every allocation rule and every
$K$. At $K=1$, $p_i$ is a standard task-sampling probability. At $K=M$, each
task enters the update.

\paragraph{Taskwise AdamW second moment.}
Conventional AdamW inserts $\widehat g^2$ into its second-moment average. The
expectation of this square changes with $p_i$. That change also alters future
AdamW scaling, which makes sampler comparisons harder to interpret. We use
\begin{equation}
    \widehat u=\sum_{i\in B}\frac{w_i}{p_i}g_i^2,
    \label{eq:taskwise_square_observation}
\end{equation}
where the square is element-wise. The first-moment average receives
$\widehat g$, and the second-moment average receives $\widehat u$. Its
conditional target is
\begin{equation}
    \mathbb E[\widehat u]=\sum_i w_i\mathbb E[g_i^2],
    \label{eq:consistent_second_moment_target}
\end{equation}
which stays fixed as $p_i$ and $K$ change. We call this update
\emph{taskwise AdamW}. Bias correction, learning-rate scheduling, clipping, and
weight decay follow the same implementation used by the baseline. The
experiments include conventional AdamW at $K=1$ and $K=M$ because its different
second moment can change model quality.
