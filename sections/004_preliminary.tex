\section{Preliminaries}
\label{sec:setting}

\paragraph{Multi-teacher on-policy distillation (MOPD).}
For domain $d$, the student samples a response $y\sim p_\theta(\cdot\mid x)$ to a prompt $x\sim\mathcal D_d$. The assigned teacher $q_d$ scores the student prefixes $h_t=(x,y_{<t})$. Given token loss $\ell_{d,t}$ and target domain weights $\lambda_d\geq0$ with $\sum_d\lambda_d=1$, we take the domain-response (DR) objective as our reference:
\begin{equation}
\mathcal L_{\mathrm{DR}}(\theta)=\sum_d\lambda_d\,
\mathbb E_{x\sim\mathcal D_d,\,y\sim p_\theta(\cdot\mid x)}
\left[\frac{1}{|y|}\sum_{t=1}^{|y|}\ell_{d,t}(\theta)\right].
\label{eq:mopd}
\end{equation}
This averages tokens within each response, then responses within each domain, and combines domains using $\lambda_d$. Below, we define its batch counterpart and two alternative averaging rules that change the relative weights of domains or responses. Training holds sampled responses, masks, and averaging weights fixed when differentiating; fresh responses are generated at each update.

\paragraph{Sampled-token, top-$k$, and full-vocabulary supervision.}
These choices determine which vocabulary alternatives receive teacher feedback at each prefix. Write $p_\theta(v)=p_\theta(v\mid h_t)$ and $q_d(v)=q_d(v\mid h_t)$. Full-vocabulary supervision computes reverse KL over the vocabulary $\mathcal V$:
\begin{equation}
\ell_{\mathrm{full}}=\sum_{v\in\mathcal V}p_\theta(v)\log\frac{p_\theta(v)}{q_d(v)}.
\label{eq:full}
\end{equation}
Sampled-token supervision (PG) uses only the generated token $a=y_t$:
\begin{equation}
\ell_{\mathrm{PG}}(a)=-\sg[\log q_d(a)-\log p_\theta(a)]\log p_\theta(a),
\qquad a\sim p_\theta.
\label{eq:pg}
\end{equation}
Here $\sg$ stops gradients through the log-ratio coefficient. At a fixed prefix, averaging this gradient over $a\sim p_\theta$ recovers the full-vocabulary reverse-KL gradient (Appendix~\ref{app:losses}).

Top-$k$ supervision uses the $k$ most probable tokens under the student or teacher. We use their intersection: let $S$ and $T$ be the student and teacher top-$k$ sets fixed at rollout, and $I=S\cap T$. The loss is
\begin{equation}
\ell_{\mathrm{top}\text{-}k}=-\sum_{v\in I}\sg\!\left[
\frac{p_\theta(v)}{\sum_{u\in S}p_\theta(u)}
\bigl(\log q_d(v)-\log p_\theta(v)\bigr)\right]\log p_\theta(v).
\label{eq:topk}
\end{equation}
The probabilities use full-vocabulary normalization; the detached weights are normalized over $S$ before restricting to $I$. An empty intersection gives zero loss. We call the number of supervised alternatives \emph{supervision density}.

\paragraph{Loss averaging.}
Let $\mathcal B=\bigcup_d\mathcal B_d$ be a rollout batch, with $\mathcal B_d$ containing the nonempty responses from domain $d$; assume every domain is represented. Let $T_i$ be response $i$'s valid-token count and $\ell_i=T_i^{-1}\sum_t\ell_{i,t}$ its mean loss over valid tokens. For averaging rule $A\in\{\mathrm{GT},\mathrm{DT},\mathrm{DR}\}$, the batch loss is
\begin{equation}
\widehat{\mathcal L}_{A}(\theta;\mathcal B)
=\sum_{i\in\mathcal B}w_i^{A}\ell_i(\theta).
\label{eq:batch_loss}
\end{equation}
Here $w_i^{A}$ is the resulting response weight, determined by the averaging rule rather than an additional free coefficient. For $i\in\mathcal B_d$, the three rules give
\begin{equation}
w_i^{\mathrm{GT}}=\frac{T_i}{\sum_{j\in\mathcal B}T_j},\qquad
w_i^{\mathrm{DT}}=\frac{\lambda_dT_i}{\sum_{j\in\mathcal B_d}T_j},\qquad
w_i^{\mathrm{DR}}=\frac{\lambda_d}{|\mathcal B_d|}.
\label{eq:averaging}
\end{equation}
Substituting $w_i^{\mathrm{DR}}$ gives the sample-average counterpart of Equation~\ref{eq:mopd}:
\begin{equation}
\widehat{\mathcal L}_{\mathrm{DR}}(\theta;\mathcal B)
=\sum_d\lambda_d\frac{1}{|\mathcal B_d|}
\sum_{i\in\mathcal B_d}\left[\frac{1}{T_i}\sum_t\ell_{i,t}(\theta)\right].
\label{eq:dr_batch}
\end{equation}
Thus $\lambda_d$ sets the domain's total weight, while $w_i^{\mathrm{DR}}=\lambda_d/|\mathcal B_d|$ distributes it equally across that domain's responses. Domain-token (DT) averaging preserves the same domain weights but distributes them in proportion to response length. Global-token (GT) averaging additionally replaces the target domain weights with observed domain token shares. GT and DT therefore generally reweight the reference objective, rather than merely providing different estimates of it.

\paragraph{Gradient conflict.}
We measure conflict between optimizer updates. Starting from identical copies of the student and optimizer state, apply one optimizer step using domain $d$'s mean loss and let $u_d=\theta_d^+-\theta$ be the resulting parameter change. For nonzero updates, define $C_{de}=(u_d^\top u_e)/(\|u_d\|\,\|u_e\|)$. Negative values indicate opposing update directions; positive values indicate alignment.
