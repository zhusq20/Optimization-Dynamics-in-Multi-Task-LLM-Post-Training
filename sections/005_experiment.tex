\section{Experiments}
\label{sec:experiments}
% ============================================================================

We use three experiments. A controlled Gaussian problem verifies the sampling
calculation. Frozen LLM gradients test response normalization and proposal
quality without full training runs. Four-teacher MOPD runs measure progress per
token and GPU hour, followed by a smaller GRPO transfer study. The controlled
experiment is complete; the large-model experiments remain pending.

\subsection{Controlled validation of the sampling rule}
\label{sec:controlled_experiment}

We construct three Gaussian task-gradient distributions with different raw
gradient scales, AdamW coordinate scales, and task costs. All methods target
$\lambda_i=1/3$ and apply the correction in
Equation~\ref{eq:importance_estimator}. We draw 20,000 Monte Carlo trials, with
16 corrected task gradients per trial. We omit the probability floor here so
that the proposals match the closed-form calculation.

Under the identity metric used by SGD, Raw GPAS is optimal and attains
calculated and Monte Carlo error ratios of $0.534$ relative to uniform
sampling. Figure~\ref{fig:controlled_sampling} evaluates the same problem in
the AdamW metric. The calculated GPAS error ratio is $0.698$, and the Monte
Carlo ratio is $0.697$. The raw-gradient proposal reaches $7.178$ times the
observed uniform error because its largest raw coordinates receive a small
AdamW scale. Cost-GPAS reaches $0.893$ times the uniform time-weighted
second-moment proxy. Every corrected proposal has a relative AdamW-scaled
mean-gradient error below $2.1\%$.

    \caption{Controlled sampling experiment. Bars show Monte Carlo results
    normalized by the observed uniform baseline; black crosses show calculated
    error ratios. Task costs are $5$, $2$, and $10$. Lower values are better

\subsection{Four-teacher MOPD setup}
\label{sec:exp_setup}

The MOPD study uses a fixed revision of Qwen3-1.7B
\citep{qwen2025qwen3}. Four teachers start from this checkpoint and receive
separate post-training on mathematics, code, instruction following, and
science question answering. The teachers are frozen during MOPD. We report the
model and tokenizer revisions, teacher checkpoints, and each teacher's score
on its training domain. On a shared set of initial-student rollouts, we also
report response-normalized reverse KL and the 99th percentile of the absolute
teacher--student token log-probability gap.

Each optimizer step samples one task and uses one task-homogeneous batch. Every
response is averaged over its valid tokens, responses are then averaged within
the task, and one shared task-gradient clip is applied. The trainer records the
sampling score before multiplying the gradient by $\lambda_i/q_i$ and calling
AdamW. All methods target $\lambda_i=1/4$ and use the same data splits.

Each task batch targets 65,536 valid response tokens. The prompt count is
estimated from the task's recent response lengths, and every completed response
enters the update. Runs use 600 optimizer steps, an 8,192-token response cap,
temperature 1, top-$p$ 1, disabled thinking mode, an eight-step round-robin
warm start, $\gamma=0.95$, and $q_{\min}=0.05$. We run seeds 42, 43, and 44.
Within each seed, methods share the initialization, data order, and evaluation
prompts.

\subsection{Methods}
\label{sec:exp_methods}

Table~\ref{tab:exp_methods} compares two fixed-target baselines with GPAS and
Cost-GPAS. Loss-EMA is a simple difficulty sampler based on the current
response-normalized teacher loss. It uses the same moving-average rate and
probability floor as GPAS, and the same importance correction keeps its target
mixture fixed. Raw GPAS is evaluated only on frozen gradients to isolate the
effect of the AdamW metric; it does not require another training run.

\begin{table}[H]
\centering
\small
\caption{MOPD methods. Every method uses three training seeds and the same
target mixture.}
\label{tab:exp_methods}
\begin{tabular}{lll}
\hline
Method & Task proposal & Gradient factor \\
\hline
Uniform & $q_i=1/4$ & $1$ \\
Loss-EMA & $q_i\propto\lambda_i\widehat\ell_i$
    & $\lambda_i/q_i$ \\
GPAS & $q_i\propto\lambda_i\widehat s_i$
    & $\lambda_i/q_i$ \\
Cost-GPAS & $q_i\propto\lambda_i\widehat s_i/\sqrt{\widehat c_i}$
    & $\lambda_i/q_i$ \\
\hline
\end{tabular}
\end{table}

Here $\widehat\ell_i$ is the moving average of response-normalized teacher
loss, $\widehat s_i^2$ tracks $\|A_tG_i\|_2^2$ in the AdamW metric, and
$\widehat c_i$ tracks total task time. The common floor is applied after each
proposal is formed.

\subsection{Frozen-gradient mechanism study}

We save steps 0, 300, and 600 from the seed-42 Uniform run. At each checkpoint,
we collect 16 gradient batches per task. The first eight estimate task scores
and costs; the other eight evaluate the resulting proposals.

\paragraph{Response normalization.}
\label{sec:exp_length_cost}
Using the same cached responses, we compare a prompt-balanced batch with global
token averaging against Equation~\ref{eq:response_normalized_update} followed
by an equal task average. We report response length, the task share induced by
global token averaging, and the coefficient after response normalization.

\paragraph{Proposal quality.}
\label{sec:exp_estimator}
The held-out half of the gradient bank evaluates Uniform, Loss-EMA, Raw GPAS,
GPAS, and Cost-GPAS. We report the AdamW-scaled estimator error $M(q)$ from
Equation~\ref{eq:empirical_estimator_mse} and the compute score $J(q)$ from
Section~\ref{sec:cost_gpas}, both relative to Uniform. Monte Carlo resampling
also compares each corrected mean with the four-task full-mixture mean. This
single evaluation tests the importance correction, the benefit of the AdamW
metric over raw gradient norms, and the cost-aware proposal.

\paragraph{AdamW score.}
\label{sec:exp_geometry_tracking}
For every cached task gradient, we compute the task-dependent part of the next
AdamW parameter update from the saved first- and second-moment state. Spearman
correlations compare the raw gradient norm and the lagged AdamW-metric norm
with the resulting update norm.

\subsection{End-to-end MOPD efficiency}
\label{sec:exp_allocation}

Every 50 steps, evaluation on shared held-out prompts measures weighted teacher
loss
\begin{equation}
    L(N)=\sum_i\lambda_i\ell_i(N),
    \label{eq:weighted_teacher_loss}
\end{equation}
where $N$ is cumulative valid response tokens or measured GPU hours. We report
normalized teacher-loss AUC over the resource range shared by the compared
methods and the final weighted and per-task losses. The token comparison is
GPAS against Uniform and Loss-EMA; the time comparison is Cost-GPAS against
Uniform and GPAS. Results are means and standard deviations over the three
training seeds.

The final capability evaluation reports MATH-500 greedy pass@1, a frozen
post-cutoff LiveCodeBench pass@1 slice, IFBench strict accuracy, and
GPQA-Diamond average@4. The table includes all four task scores and their macro
average. Training logs retain the sampled task, proposal probability,
importance factor, valid-token count, prompt count, total GPU time, gradient
scores, and teacher loss.

\subsection{Transfer to multi-task GRPO}
\label{sec:exp_grpo}

The transfer study uses MATH train, APPS train, and ARC-Challenge train with
executable or exact-match rewards
\citep{hendrycks2021math,hendrycks2021apps,clark2018arc}. Uniform, GPAS, and
Cost-GPAS target $\lambda_i=1/3$ and use the same task-level correction as in
MOPD. Each task-homogeneous batch targets 32,768 response tokens and samples
eight responses per prompt. Runs use a six-step round-robin warm start, 400
optimizer steps, AdamW, and seeds 42, 43, and 44.

We report weighted held-out KL-regularized return against tokens and GPU hours,
together with final MATH-500, APPS test pass@1, and ARC-Challenge accuracy.
This comparison changes only the task sampler and therefore tests whether the
same allocation rule transfers from distillation gradients to reward-based
updates.
