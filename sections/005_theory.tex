\section{GPAS Task Allocation}
\label{sec:theory}
% ============================================================================

\subsection{Optimizer-scaled task scores}

Let $D$ be the current diagonal scaling applied by the optimizer, excluding the
shared learning rate. For SGD, $D$ is the identity. For AdamW, $D$ comes from
the current second-moment state. GPAS summarizes task $i$ with
\begin{equation}
    r_i^2=\mathbb E\|Dg_i\|_2^2.
    \label{eq:optimizer_metric}
\end{equation}
This score is measured from completed task units. It includes both the task's
mean gradient and sampling noise inside a task unit.

For a fixed expected task width, the part of the scaled estimator error that
depends on the inclusion probabilities has the simple form
\begin{equation}
    V(p)=\sum_i\frac{(w_i r_i)^2}{p_i},
    \qquad \sum_i p_i=K.
    \label{eq:optimizer_metric_mse}
\end{equation}
Appendix~\ref{app:variance} gives the calculation and the pairwise correction
for exact-$K$ sets. The frozen-gradient experiment measures the complete error,
so the empirical test includes that correction.

We limit every inclusion probability to $p_{\min}\leq p_i\leq1$. Minimizing
Equation~\ref{eq:optimizer_metric_mse} gives
\begin{equation}
    p_i=\operatorname{clip}\!\left(\frac{w_i r_i}{z},
    p_{\min},1\right),
    \label{eq:gpas_proposal}
\end{equation}
where the scalar $z$ makes the probabilities sum to $K$. A fixed-size sampler
then draws exactly $K$ tasks with these marginals. We call this rule GPAS. The
four-task study uses the maximum-entropy distribution over all possible task
sets with the required marginals. Enumeration gives exact marginals and
pairwise probabilities.

The warm-start diagnostic is
\begin{equation}
    H_K=\frac{V(p^{\rm uniform})}{V(p^{\rm GPAS})}.
    \label{eq:effect_headroom}
\end{equation}
$H_K$ is a local estimator-error ratio. A value near one predicts little room
for adaptive allocation at that checkpoint. Training curves determine whether
the local difference improves loss.

\subsection{Cost-GPAS and online measurement}

Let $t_i$ be the predicted critical-path time of task $i$. With one resident
teacher slot, the predictor uses the current resident teacher, recent transfer
tail, rollout, scoring, and backward times. The additive time model leads to
\begin{equation}
    J(p)=\left(\sum_i p_i t_i\right)V(p).
    \label{eq:cost_objective}
\end{equation}
When the probability limits are inactive, the solution is
\begin{equation}
    p_i\ \propto\ \frac{w_i r_i}{\sqrt{t_i}}.
    \label{eq:cost_gpas_proposal}
\end{equation}
We solve the bounded problem directly for the four-task setting. At $K>1$, the
solver scores every possible task set with its predicted time under the fixed
teacher order and optimizes the distribution over those sets. Importance
weights use the resulting inclusion probabilities. We call this allocation
Cost-GPAS. The final systems comparison uses measured GPU hours.

Selected task units update exponential averages of $r_i^2$ and task time. A
round-robin warm start initializes every task. An estimate older than
$A_{\max}$ processed task units triggers a small, counted probe. The probe runs
rollout, teacher scoring, and backward and leaves the student parameters fixed.
Its response count and GPU time enter the resource totals. Section~\ref{sec:experiments}
tests the price of these refreshes directly.

GPAS training repeats four steps: refresh an expired score, compute bounded
inclusion probabilities, draw an exact-$K$ task set, and apply
Equations~\ref{eq:importance_estimator} and
\ref{eq:taskwise_square_observation}. The sampler state is saved with the
optimizer state for exact resumption.
