\section{Gradient-Preserving Adaptive Sampling}
\label{sec:theory}
% ============================================================================

Section~\ref{sec:update_interface} fixes the target task mixture and leaves the
sampling probabilities available for compute allocation. Every expectation in
this section conditions on the model, optimizer, and sampler state before the
next task is selected.

\subsection{Sample tasks in the optimizer metric}

Let $A_t$ be a linear map determined by the optimizer state before task
selection. It maps gradients into the local update geometry whose estimation
error we seek to reduce. Conditional on the training history, $A_t$ is fixed.
Suppressing the step index, define
\begin{equation}
    \widetilde G_i=A_tG_i,
    \qquad
    s_i=\sqrt{\mathbb E\|\widetilde G_i\|_2^2}.
    \label{eq:optimizer_metric}
\end{equation}
For SGD, $A_t=I$; its scalar learning rate does not change the proposal. Thus
the SGD instance is Raw GPAS. For AdamW, raw gradient norms can be misleading
because parameter coordinates have different effective step sizes. Let
$\bar v_{\mathrm{prev}}$ be AdamW's stored, bias-corrected second moment before
task selection. Its lagged metric is
\begin{equation}
    A_t^{\mathrm{AdamW}}G_i
    =\frac{G_i}{\sqrt{\bar v_{\mathrm{prev}}}+\epsilon_{\mathrm{Adam}}},
    \label{eq:adamw_lagged_metric}
\end{equation}
where division is element-wise. The LLM experiments use this instance and call
it GPAS unless stated otherwise.

For the corrected task gradient in
Equation~\ref{eq:importance_estimator}, the optimizer-metric mean-squared error
is
\begin{equation}
    \mathbb E\|A_t(\widehat g-h)\|_2^2
    =\sum_i\frac{\lambda_i^2s_i^2}{q_i}-\|A_th\|_2^2.
    \label{eq:optimizer_metric_mse}
\end{equation}
The part that depends on the proposal is
\begin{equation}
    V(q)=\sum_i\frac{\lambda_i^2s_i^2}{q_i}.
    \label{eq:preconditioned_second_moment}
\end{equation}
\begin{proposition}[Optimizer-metric-optimal task proposal]
\label{prop:gpas_optimality}
If $\lambda_i s_i>0$ for every task, $V(q)$ over the probability simplex is
minimized by $q_i^\star=\lambda_i s_i/\sum_j\lambda_j s_j$.
\end{proposition}
\begin{proof}
Cauchy--Schwarz and $\sum_iq_i=1$ give
\begin{equation}
    \left(\sum_i\lambda_i s_i\right)^2
    =\left(\sum_i\sqrt{q_i}\,
      \frac{\lambda_i s_i}{\sqrt{q_i}}\right)^2
    \leq \left(\sum_iq_i\right)V(q)=V(q).
    \label{eq:gpas_cs_bound}
\end{equation}
Equality requires $q_i\propto\lambda_i s_i$, which proves the claim.
\end{proof}
The identity metric makes the result the classical SGD gradient-norm rule. For
AdamW, GPAS uses the stored state because the score must be available before
task selection. This lagged score approximates the task-dependent part of the
next AdamW step; E3 compares it with a measured AdamW task step.

\subsection{Include measured task cost}
\label{sec:cost_gpas}

Fixed-token task batches can have different runtimes. Let $c_i$ be the measured
time for generation, teacher or reward evaluation, actor training, and the
optimizer step. Cost-GPAS minimizes the local compute score
$J(q)=(\sum_i q_i c_i)V(q)$.
\begin{corollary}[Cost-aware task proposal]
\label{cor:cost_gpas}
If additionally $c_i>0$, the minimizer of $J(q)$ is
$q_i^\star=(\lambda_i s_i/\sqrt{c_i})/
\sum_j(\lambda_j s_j/\sqrt{c_j})$.
\end{corollary}
\begin{proof}
Cauchy--Schwarz gives
$J(q)\geq(\sum_i\lambda_i s_i\sqrt{c_i})^2$, with equality exactly when
$q_i\propto\lambda_i s_i/\sqrt{c_i}$.
\end{proof}
This applies the cost-aware sampling rule of
\citet{mohri2026costawarelearning} to complete task batches in the selected
optimizer metric. $J(q)$ is a local training signal. E2 measures it on held-out
gradient banks, and the end-to-end experiment measures weighted teacher loss
against GPU hours.

\subsection{Estimate the scores online}
\label{sec:gpas}

After task $i$ completes, GPAS updates one moving average,
$\widehat s_i^2\leftarrow\gamma\widehat s_i^2+
(1-\gamma)\|\widetilde G_i\|_2^2$.
Cost-GPAS applies the same update to measured task time. A round-robin warm
start observes every task. After computing the proposal, the implementation
sets probabilities below $q_{\min}$ to the floor and renormalizes the remaining
entries. The floor limits score staleness and large importance weights.

Score error changes sampling efficiency smoothly. Appendix
\ref{app:score_approximation} shows that a relative score error of at most
$\delta$ increases $V(q)$ by at most a factor of $1/(1-\delta^2)$. E2 evaluates
the proposal with held-out gradients, and E3 compares the online moving average
with fresh task scores.

Each completed step records the clipped task gradient before the importance
correction. The trainer then multiplies the gradient by $\lambda_I/q_I$ and
passes it to the optimizer. Gradient clipping is applied before the correction
so the conditional mean in Equation~\ref{eq:importance_unbiased} matches the
stated training objective. The experiments use AdamW; changing the optimizer
changes the metric, not the correction.
