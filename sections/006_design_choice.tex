% ============================================================================
\section{Practical Training Recipe}
\label{sec:training_guide}
% ============================================================================

\paragraph{1. Fix the objective.}
Define a task unit with fixed prompt and response counts. Average token loss
within each response. Measure each initial task loss at the shared checkpoint
and freeze the normalized objective weights.

\paragraph{2. Profile the candidate task widths.}
Run a round-robin warm start. Measure optimizer-scaled gradient magnitude and
critical-path time for every task. Compute $H_K$ for each candidate $K$ and
record memory and transfer traces.

\paragraph{3. Draw an exact-$K$ set.}
Compute bounded GPAS or Cost-GPAS inclusion probabilities. Draw exactly $K$
tasks with those marginals. Add $w_i g_i/p_i$ to the gradient accumulator and
$w_i g_i^2/p_i$ to the taskwise second-moment accumulator as each unit finishes.

\paragraph{4. Stream teachers.}
Use the same residency policy for every $K$. With one slot, serve the resident
teacher first, prefetch the next teacher when memory permits, and keep the final
teacher resident. Record every transfer phase and the end-to-end critical path.

\paragraph{5. Refresh and save sampler state.}
Run a counted probe when a score reaches the age limit. Save probabilities,
selected sets, score and time averages, ages, probe state, response counts,
transfer state, and both optimizer accumulators. A resume test reproduces the
next set and optimizer update.
